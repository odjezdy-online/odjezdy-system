# PID assets

The SVG icons in this folder (accessible, snowflake, logo_pid, metro-a/b/c, info) come from the PID virtual
departure board, https://data.pid.cz/departures/ ("departure-boards", Pražská integrovaná doprava), which is
published under the MIT License, see `LICENSE-PID-MIT.txt` (Copyright (c) 2020 Pražská integrovaná doprava).
They are used by the `pid` theme only. "PID" and the logo are marks of Pražská integrovaná doprava; this project
is not affiliated with or endorsed by PID.

The theme also uses the typeface *Prague Citizen* when its files (`PragueCitizen-*.ttf`) are present in
`app/fonts/ttf/`; they are not part of this repository (the font files carry "Copyright (c) 2022 Matyáš Machát.
All rights reserved." and no separate licence), without them the theme falls back to Fira Sans.
